# Documentação do VozAtiva

Índice de tudo o que existe em `docs/` e do que cada arquivo responde. Para uma visão geral do projeto (o que é, como rodar, como testar), comece pelo [README principal](../README.md).

| Documento | Responde a... | Para quem |
|---|---|---|
| [`ARQUITETURA.md`](ARQUITETURA.md) | Como o código está organizado? Quais são as telas, o modelo de dados e onde mexer para cada tipo de mudança? | Quem vai ler ou alterar o código |
| [`ROADMAP.md`](ROADMAP.md) | O que já está implementado, o que está planejado e o que é só possibilidade? | Banca, avaliadores, quem quer evoluir o projeto |
| [`MODELO-DE-NEGOCIO.md`](MODELO-DE-NEGOCIO.md) | Como o projeto poderia ser monetizado? Quais concorrentes, preços e custos? (Nenhuma decisão de comercializar foi tomada.) | Banca, possíveis parceiros |
| [`FETIN-2026.md`](FETIN-2026.md) | Qual foi o reconhecimento na 45ª FETIN? Quais textos e infográfico foram enviados à revista? | Qualquer visitante |
| [`CONTEXTO_PROJETO_v5.txt`](CONTEXTO_PROJETO_v5.txt) | Por que cada decisão foi tomada? O que mudou em cada rodada de trabalho? | Quem precisa do histórico completo |

Também vale conhecer:

- [`../fonemas-audio/LEIA-ME.txt`](../fonemas-audio/LEIA-ME.txt) — como funciona a pasta de áudios dos fonemas (65 por voz) e como trocar ou adicionar gravações.
- [`../identidade-visual/`](../identidade-visual/) — logo, QR code do repositório e imagem de pré-visualização (1280 × 640) usada nas configurações do GitHub.
- [`fetin/`](fetin/) — infográfico do relatório da FETIN (1400 × 1400).

## Convenção de status

Nos documentos de planejamento (`ROADMAP.md` e `MODELO-DE-NEGOCIO.md`):

- ✅ **Implementado** — existe no código, testado, em uso.
- 📋 **Planejado** — decidido como próximo passo, ainda não iniciado.
- 💡 **Possibilidade** — levantado em análise, sem decisão de fazer.
